# Arquitectura del sistema – Finca Catalina

## Objetivo

Organizar los componentes del sistema de gestión de residuos orgánicos agroindustriales.

## Componentes principales

* **Interfaz de usuario:** permite registrar y consultar información.
* **Lógica del sistema:** procesa las operaciones y aplica las reglas del negocio.
* **Gestión de datos:** permite almacenar y consultar la información.
* **Módulo de seguimiento:** permite revisar los estados de los procesos.

## Patrón de diseño State

Permite representar los diferentes estados de un proceso y controlar sus transiciones.

## Patrón de diseño Observer

Permite notificar a los componentes interesados cuando ocurre un cambio de estado.

## Nota

Este documento describe la arquitectura conceptual propuesta para el proyecto académico.
