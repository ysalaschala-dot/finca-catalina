# Gestión de riesgos y métricas de calidad

## 1. Riesgos del proyecto

| Riesgo                   | Probabilidad | Impacto | Acción preventiva                          |
| ------------------------ | ------------ | ------- | ------------------------------------------ |
| Pérdida de información   | Media        | Alto    | Mantener respaldos y usar GitHub           |
| Errores en los registros | Media        | Alto    | Validar los datos ingresados               |
| Retrasos en las entregas | Media        | Medio   | Organizar actividades mediante Scrum       |
| Fallos en el sistema     | Media        | Alto    | Realizar pruebas antes de integrar cambios |

## 2. Calidad del software

Se propone evaluar la calidad del sistema teniendo en cuenta aspectos como funcionalidad, confiabilidad, usabilidad y mantenibilidad, tomando como referencia ISO/IEC 25010.

## 3. Métricas con GQM

**Objetivo:** evaluar la calidad del sistema propuesto.

* **Pregunta:** ¿se registran correctamente los datos?
* **Métrica:** porcentaje de registros válidos.
* **Pregunta:** ¿se cumplen las actividades planeadas?
* **Métrica:** porcentaje de tareas terminadas frente a las planificadas.

## 4. Observación

Las métricas deben calcularse con resultados reales de pruebas. No se asignan porcentajes de cumplimiento hasta contar con datos verificables.
