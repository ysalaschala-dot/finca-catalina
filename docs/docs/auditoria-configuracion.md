# Auditoría de gestión de configuración

## Proyecto

Sistema de Gestión de Residuos Orgánicos Agroindustriales – Finca Catalina.

## Objetivo

Documentar la organización de archivos, las ramas y el control de cambios del proyecto mediante GitHub.

## Ramas del repositorio

* `main`: contiene la versión principal del proyecto.
* `develop`: permite integrar cambios antes de incorporarlos a la versión principal.
* `feature/oci-001-recepcion`: se utiliza para desarrollar la funcionalidad relacionada con OCI-001.

## Elemento de configuración OCI-001

**Nombre:** Recepción de residuos orgánicos.

**Descripción:** Documento de referencia para definir el registro y seguimiento de la recepción de residuos orgánicos agroindustriales.

**Control de cambios:** Las modificaciones deben registrarse mediante commits y revisarse antes de integrarse en otra rama.
